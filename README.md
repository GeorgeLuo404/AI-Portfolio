# AI Portfolio

George Luo's portfolio, with an AI twin chat, built with Next.js. The site is being rebuilt from the design in [`docs/DESIGN.md`](docs/DESIGN.md), task by task, as planned in [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Credits

This project is based on the [Next-Gen AI Portfolio](https://github.com/sonnysangha/next-gen-ai-portfolio-openai-agentkit-sanity-clerk-nextjs-16) by Sonny Sangha and its original tutorial. See that repository for its license terms.

## Develop

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000). The design prototype lives in `design/`. See `docs/DESIGN.md` for how to run it.
